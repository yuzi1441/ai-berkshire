看板前端设计方案

3 套方向 · 全部基于 2026-08-29 真实看板数据 · 每个页面均可直接缩放窗口体验移动端布局 · 点击卡片进入预览

方案 A

决策终端

桌面优先的高密度专业终端。一屏 15+ 只股票，价格档位条放在正中间，现价在报告区间里的位置一眼可见。左侧常驻筛选栏。

适合：每天在电脑前快速扫描全部 229 只

 方案 B

行动驾驶舱

打开第一眼只有「今天需要你处理的 8 只」：可执行、分歧/否决、接近机会，按行动分组。其余 200+ 只收进第二层。工具面板全部收纳。

适合：每天只想知道「现在有没有事」

 方案 C

清晰卡片（移动优先）

浅色主题、大字号、大触控目标。每股一张 96px 紧凑卡，按「可执行 / 待裁决 / 待验证 / 等待价格 / 回避」分组，点卡片弹底部详情。

适合：主要在手机上刷，通勤/碎片时间看

 方案 D · 推荐 ★

溯源中间态（完整多分区）

保留全部工作模块与分区：买入前决策（含三套分区筛选、每日机会）、双模型复核（五类对照分区、Z/DS 任务矩阵）、买入后跟踪（论文健康度+指标）、市场工具抽屉。每个数字都带来源+时间戳，顶栏是数据管线时间线。

定位：简洁与多数据的中间态 · 防误判优先

三套方案共同修复的交互问题（不管选哪个都会改）

  • 关键信息前置：交易时段、行情新鲜度、可分批/可小仓/待验证/分歧 计数，做成吸顶状态条——滚动到哪里都能看到，替代现在要滚 5 屏才能到股票列表的问题。
  • 价格档位可视化：新增「报告价格档 × 现价位置」条，替代现在纯文字的「现价高于报告可执行价格区间」。现价落在哪个档、离下一档差多少，一眼可见。
  • 冲突显性化：主报告说可买但 Checklist 否决（分众）、双模型分歧（恒瑞）这类状态，用醒目警示徽章直接标在列表行，不再埋进详情。
  • 筛选瘦身：现在 10 个「当前可执行」chips + 8 个「参考分区」+ 8 个「人工复核」共 26 个筛选钮压在列表上方。改为按行动分组的 4-6 个主筛选，参考分区/人工复核收进高级抽屉。
  • 指数/年报日历/自动化状态收纳：从首屏主体位置移到「市场工具」抽屉，需要时再打开。
  • 详情交互统一：桌面 = 行内展开（保留现有习惯）；手机 = 底部弹层（符合拇指操作），支持下滑关闭。
  • 行情陈旧显性化：行情超过 10 分钟，顶栏 + 行内价格都带「陈旧」标记，避免误把旧价当实时价。
  • 保留的能力：50 行懒加载、详情按需加载、双模型复核页、买入后跟踪、j/k 键盘导航、报告原文链接。
