## 第二步：生意本质分析

联影医疗的本质不是简单“卖机器”，而是 **以高端医学影像和放疗设备为入口，向医院提供诊断、治疗、科研、服务和数字化能力的长期系统供应商**。

| 生意变量 | 分析 |
|---|---|
| 客户是谁 | 大型三甲医院、区域医疗中心、县域医院、海外医疗机构及经销渠道。 |
| 客户为什么付钱 | 医院需要提升诊断/治疗能力、满足设备更新、学科建设、科研和患者服务需求；高端设备直接影响科室能力和医院评级。 |
| 收入是否重复 | 硬件一次性交付占大头；维修服务随装机量增长，2025 年服务收入 17.08 亿元、毛利率 61.86%，是更优质的重复收入。 |
| 真正利润变量 | 产品组合升级、国产替代份额、海外渠道效率、研发费用率、应收回款、服务收入占比。 |
| 资本占用 | 存货、应收账款和研发投入占用较重；2025 年研发投入 26.21 亿元，占收入 18.99%。 |
| 周期属性 | 医疗设备受招采、财政预算、医院资本开支和政策节奏影响，2024 年收入下滑就是提醒。 |

联影的商业模式优点在于：
- 高端设备一旦进入医院，售后服务、软件升级、培训和后续采购会形成粘性。
- 产品线覆盖 MR、CT、MI、XR、RT、超声、生命科学仪器等，可做跨科室综合方案。
- 设备更新政策和国产替代提供中期顺风。

缺点也明显：
- 硬件制造和医疗招采决定了它难以像纯软件那样轻资产、高净利率。
- 客户议价能力强，回款周期和项目验收可能导致现金流波动。
- 国际化不是“卖出去”就结束，售后、认证、临床证据和品牌信任需要长期投入。

### 2. 聪明人为什么不买

- **估值不便宜**：TTM PE 约 46.35x、TTM PS 约 6.18x，需要较长时间高增长消化。
- **2026Q1 增速不算惊艳**：收入 +17.34%，归母净利 +7.78%，扣非净利 -1.75%，并不足以支撑无限乐观定价。
- **现金流季节性强**：2025 全年经营现金流好，但 2026Q1 为 -9.59 亿元，不能只看单年修复。
- **行业不是赢家通吃**：医学影像设备高度专业、分产品线竞争，GE/西门子/飞利浦的临床证据和品牌资产很难快速被复制。
- **政策红利可能伴随控价**：国产替代和设备更新带来需求，但招采和医保控费也可能压低价格。

### 3. 历史类比

联影更像“国产高端制造出海”的优秀样本，而不是互联网平台型生意。可类比迈瑞医疗早期的国际化与产品升级路径，但影像设备资本品属性更强、项目制更明显，现金流和验收周期更重。

## 第六步：行业与文明趋势

高端医学影像设备处在三个趋势交汇处：

1. **医疗资源均衡化**：国家区域医疗中心、县域医共体和基层能力建设推动设备下沉。
2. **国产替代深化**：高端 CT、MR、PET/CT、DSA 等过去高度依赖进口，国产品牌技术进步带来替代空间。
3. **AI 与精准医疗**：影像设备不再只是硬件，而是数据采集、诊断辅助、治疗规划和科研平台入口。

但必须区分“行业趋势好”和“股东回报好”：
- 行业扩容不代表所有公司都有高 ROIC。
- 设备更新政策会释放需求，也会带来集中招采与价格压力。
- AI 影像价值链中，医院数据、算法公司、设备厂、云平台都可能分走价值。

联影在价值链中处于硬件与临床工作流入口位置，价值捕获能力强于单纯零部件供应商，但弱于高毛利纯软件平台。它最理想的演化路径是：硬件装机扩大 → 服务与软件占比提高 → 海外高端客户认可 → 研发规模效应显现。

> 李录式追问：站在 20 年后看，联影更可能是“中国高端医疗装备全球化的代表公司”，还是“只在国内政策窗口期成长过的一轮周期股”？答案取决于海外渠道和服务网络，而不是只取决于国内订单。

### 2. 反向 DCF 直觉

现价约 46x TTM PE。若 5 年后市场愿意给 30x PE，要获得约 10% 年化回报，EPS 需要从约 2.30 元增长到约 6.4 元，五年 CAGR 约 23%。这要求：
- 国内设备更新不只是一次性脉冲；
- 海外收入维持高增且不牺牲毛利率；
- 研发费用率逐步释放经营杠杆；
- 现金流与应收存货控制同步改善。

这不是不可能，但难度不低。
