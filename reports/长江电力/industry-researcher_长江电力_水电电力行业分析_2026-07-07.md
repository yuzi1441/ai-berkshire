## 0. 一页结论

长江电力不是普通“水电现金牛”，而是一组 **长江干流不可复制水文资源 + 六库梯级调度平台 + 跨省跨区消纳体系 + 低边际成本长寿命资产**。

从芒格视角看，它符合“少变化、强约束、高确定性”的大方向：水电技术路线稳定、巨型流域资源不可复制、客户信用强、燃料成本风险低。但它不是无风险债券：来水、政策电价、市场化交易、生态/防洪约束，会让年度利润波动。

核心判断：**风光装机越高，水电的价值越不只来自电量，而来自可调节、可预测、可跨区交付的系统价值。** 长江电力长期复利的关键变量是：来水中枢、梯级调度效率、电价结构、辅助服务/容量价值兑现、财务费用与再投资纪律。

### 1.3 消纳趋势：水电价值从“低成本电量”升级为“系统调节资产”

- 2025 年全国可再生能源发电量约 3.99 万亿千瓦时，同比增长约 15%，约占全社会用电量 38.5%；其中水电 1.46 万亿千瓦时，仍是可再生能源中最稳定的大体量电源。
- 2026 年 5 月末风电+太阳能装机占比约 48.06%，显著高于水电 11.29%。风光越多，电力系统越需要可以在日内、季节内调节的水库水电。
- 2025 年 136 号文推动风电、太阳能上网电量全部进入市场，意味着新能源价格波动将更显性；这会短期压低部分时段电价，也会长期提高调峰、备用、容量价值的重要性。

### 2.3 梯级调度的本质

```text
金沙江/长江上游来水
  → 乌东德、白鹤滩：上游巨型库容与高水头
    → 溪洛渡、向家坝：承接上游调蓄，增强下游出力稳定性
      → 三峡：防洪、航运、供水、生态、发电多目标调度中枢
        → 葛洲坝：受三峡下泄影响的尾部电站
          → 华中、华东、华南负荷中心消纳
```

投资含义：同一滴水可在梯级中多次做功；库容让水从低价值时段转移到高价值时段；调度能力不直接写在资产负债表上，但会体现在节水增发、综合耗水率、事故率和枯水期韧性上。

### 2.4 气候变化影响：不是单向利好或利空

- 正向：极端天气和风光波动增加，提高大型水库在防洪、抗旱、应急保供、调峰中的系统价值。
- 负向：长期偏枯、降雨季节集中、生态流量约束加强，会压低电量中枢并降低发电自由度。
- 结论：水电的气候风险应拆成“年际来水中枢、季节分布、极端事件、政策调度优先级”四层，而不是用单年丰枯判断长期价值。

### 3.2 竞争不是价格战，而是系统位置之争

水电不是制造业，不会因为竞争者加资本开支就复制出一条长江。真正的竞争变量是：资源位置、库容调节能力、跨省消纳通道、电力市场规则、股权控制权和运营安全记录。

长江电力护城河排序：**流域资源 > 六库联调 > 跨区消纳 > 低成本融资 > 运营经验**。

## 4. 政策与电价：市场化交易、容量/辅助服务、绿色电力、输配电和消纳机制

| 政策/机制 | 最新进展 | 对水电/长江电力影响 | 来源 |
|---|---|---|---|
| 新能源上网电价市场化 | 2025 年 136 号文推动风电、太阳能上网电量全部进入市场，电价由市场交易形成 | 风光价格波动显性化；短期压低部分时段电价，长期提高调节价值 | [国家发改委解读136号文](https://www.ndrc.gov.cn/xxgk/jd/jd/202502/t20250209_1396070.html) |
| 发电侧容量电价机制 | 2026 年 114 号文系统设计调节性电源容量价值补偿，覆盖煤电、抽蓄、气电、电网侧新型储能等 | 常规大水电未必直接获得容量电价，但系统开始为“可用容量”付费，对水电调节价值定价有启示 | [国家发改委答记者问](https://www.ndrc.gov.cn/xxgk/jd/jd/202601/t20260130_1403520.html) |

| 全国统一电力市场 | 中长期、现货、辅助服务和跨省交易持续推进 | 水电收入结构从“计划/合同电量”向“合同+现货+辅助服务+绿色价值”演化 | [长江电力2025年报](https://www.ctg.com.cn/cypc/attachDir/2026/05/2026051815345898336.pdf) |

电价判断要拆四层：1）中长期/协议电量是现金流底座；2）市场化交易电量决定边际电价弹性；3）辅助服务和容量价值决定调节能力能否变现；4）绿电/绿证/碳约束决定环境价值能否形成溢价。

反身性：风光越多，短期越可能压低中午和丰水期价格；当波动积累为系统风险，市场又会反向提高调峰、备用、容量资源价值。长江电力受益于后一阶段，但前提是规则兑现。

## 5. 产业链上下游：电网客户、地方政府、流域资源、设备与运维

```text
上游资源与公共约束
  长江流域水资源 / 降雨与冰雪融水 / 防洪库容 / 生态流量 / 长江委与地方政府
        ↓
水电资产与运营
  大坝 / 水库 / 水轮发电机组 / 数字化调度 / 检修维护 / 大坝安全监测
        ↓
电力销售与消纳
  国家电网 / 南方电网 / 跨省跨区交易 / 中长期合同 / 现货市场 / 辅助服务
        ↓
终端需求
  华东、华中、华南负荷中心 / 工商业用户 / 居民用电 / 数据中心与新质生产力用电
        ↓
环境与系统价值
  绿电 / 绿证 / 碳减排 / 容量价值 / 调峰备用 / 防洪航运供水综合效益
```

| 环节 | 关键主体 | 对长江电力的约束/贡献 | 议价判断 |
|---|---|---|---|
| 上游水资源 | 自然来水、长江委、水利调度、地方政府 | 决定发电边界；防洪、生态、供水优先级会约束利润最大化 | 公司不能控制水，只能提高预测和调度效率 |
| 设备与运维 | 东方电气、哈尔滨电气、检修体系、大坝安全监测 | 巨型机组可靠性决定可用小时和安全边界 | 供应商重要，但不拥有最终议价权 |
| 电网客户 | 国家电网、南方电网 | 2025 年公司境内前两大客户销售占比接近 100%，其中国网约 68.8%、南网约 31.2% | 客户集中但信用极强；价格受政策与交易规则影响 |
| 受端省份 | 华东、华中、华南地方政府与工商业用户 | 用电增长、产业结构、电价承受能力影响消纳和电价 | 负荷中心需求越稳，长电现金流越稳 |
| 政策制定者 | 发改委、能源局、水利部门 | 决定电价、消纳、容量/辅助服务、生态流量规则 | 最大非市场变量 |

评分：1 分最弱，5 分最强。

| 维度 | 评分 | 证据 | 芒格式解释 |

| 行业少变化 | 4.5 | 水电技术成熟、资产寿命长、电力是基础需求 | 这不是快速技术迭代行业；坏处是慢，好处是可理解 |
| 进入壁垒 | 5.0 | 大江大河干流资源不可复制，审批、移民、环保、资本开支约束强 | 最好的护城河是不允许别人再挖一条河 |
| 需求确定性 | 4.5 | 中国用电量仍增长 | 电力需求不会消失，但价格不完全由企业决定 |
| 成本确定性 | 4.0 | 水电边际成本低，无煤价暴露 | 折旧、财务费用、检修和规费仍需管理 |
| 收入确定性 | 3.5 | 电量受来水影响，电价受市场化和政策影响 | 水电不是债券，天气和监管都会让利润波动 |
| 抗通胀属性 | 4.0 | 存量实物资产、低燃料成本 | 但上网电价未必完全随通胀调整 |
| 再投资空间 | 3.0 | 主业新增大水电稀缺，抽蓄、海外、并购是边际选择 | 好生意的问题是：赚的钱未必还能按同等回报再投 |
| 反身性韧性 | 4.0 | 新能源越多，系统越需要调节资源 | 规则若不给调节价值定价，价值会滞后体现在利润上 |
| 总体行业质量 | 4.3 | 稀缺资源 + 公用事业现金流 + 调节价值 | 优质慢变量行业，适合以价格纪律持有 |

### 长期复利关键变量

| 变量 | 为什么重要 | 跟踪指标 |
|---|---|---|
| 年度与季节来水 | 直接决定电量中枢 | 乌东德/三峡来水、水库水位、汛期/枯期偏离 |
| 梯级调度效率 | 同样水量下决定可发电量 | 节水增发、综合耗水率、预测精度、事故率 |
| 电价与市场化结构 | 决定收入质量 | 中长期电价、现货价差、丰枯价差、辅助服务收入 |
| 跨省消纳能力 | 决定发得出也卖得出 | 西电东送、跨省交易、受端省份负荷 |
| 财务费用与分红 | 决定股东实际回报 | 财务费用、经营现金流、分红率、资产负债率 |
| 新资产获取 | 决定长期成长 | 抽蓄项目、海外资产、并购回报、权益投资 |
| 生态与防洪约束 | 决定利润最大化边界 | 生态流量、航运、抗旱补水、防洪调度要求 |

### 反面检验：聪明人为什么不买？

| 反对理由 | 是否成立 | 我的判断 |
|---|---|---|
| 水电成长慢，高股息叙事可能推高估值 | 成立 | 好资产不等于任何价格都好 |
| 气候变化可能降低长期来水中枢 | 部分成立 | 需看流域和季节，不能用单年水文线性外推 |
| 电力市场化压低上网电价 | 部分成立 | 丰水期和午间承压，晚峰/枯期/调节服务可能补偿 |
| 政策可能要求让利实体经济 | 成立 | 公用事业天然有监管折价 |
| 风光+储能削弱水电价值 | 短期可能，长期未必 | 风光压价也制造更高调节需求 |
| 大型水库生态与移民约束 | 成立 | 新项目更难，存量更稀缺，但合规约束长期存在 |

## 7. 各维度评分与总体结论

| 维度 | 结论 | 对长江电力影响 | 信心度 |
|---|---|---|---:|
| 行业规模 | 用电需求仍增长，但装机扩张更快 | 电量需求底座稳，利用小时和电价分化 | 高 |
| 发电结构 | 风光高增，水电装机占比下降但稳定出力更稀缺 | 水电从清洁电量升级为调节资产 | 高 |
| 来水周期 | 2025 上枯下丰、秋汛密集；2026 汛期预测偏枯 | 年度电量不能机械外推 | 中高 |
| 竞争格局 | 长江电力规模、流域、调度、消纳领先 | 真正风险来自自然与政策，而非同业价格战 | 高 |
| 电价政策 | 新能源全面入市，容量/辅助服务机制完善 | 短期价格更波动，长期调节价值有望显性化 | 中高 |
| 产业链 | 上游资源不可控，下游电网信用强但议价强 | 现金流稳定，价格弹性受限 | 高 |
| 长期复利 | 来水、电价、调度、财务费用、再投资是五大变量 | 适合慢复利，不适合期待高成长爆发 | 高 |

**总体结论（行业研究员版本）**：长江电力所在的大型水电行业符合“少变化、强约束、高确定性”的大方向，但不能被简化成“永远稳定的现金牛”。更准确的定义是：

> 长江电力是中国新型电力系统中的“低碳底仓 + 季节性储能 + 跨区调节器”。长期复利不取决于水电装机还能增长多少，而取决于水文波动、电价市场化、辅助服务定价与梯级调度能力共同决定的现金流韧性。
