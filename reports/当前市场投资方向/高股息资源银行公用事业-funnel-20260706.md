## 3. 第三层：三条资产线的本质差异

### 3.1 资源高股息：真正买的是“周期下仍能分红的成本优势”

资源股的高股息最容易诱人，也最容易误判。煤炭、油气、铜金的利润并不完全由公司决定，而由商品价格、供需格局、税费政策和资本开支周期共同决定。

**本轮更偏向中国神华，而不是单纯选择股息率最高的煤炭股，原因有三点：**

1. **一体化结构降低周期波动**：煤炭、电力、铁路、港口一体化，使其不像纯煤炭公司那样完全暴露于煤价；
2. **现金流质量更可解释**：2025年净利 528.49 亿元，2026Q1净利 106.67 亿元，仍是A股资源板块中最厚的现金流机器之一；
3. **市值与流动性足够大**：9,090.04 亿元市值，适合作为组合型资产，而不是小票博弈。

陕西煤业的问题不是差，而是更偏“煤价弹性资产”；中国海油、中国石油的问题不是便宜，而是油价和政策定价权占比更高。若投资者的目标是“高股息 + 组合稳定”，中国神华更像第一选择；若目标是“资源价格反弹弹性”，中国海油和陕西煤业才更值得放进观察池。

### 3.2 银行高股息：真正买的是“系统重要性 + 低估值 + 分红纪律”

银行股表面最便宜：银行板块PE 6.55，工商银行 PE 6.82、PB 0.65，建设银行 PE 7.40、PB 0.71，招商银行 PE 6.31、PB 0.84，兴业银行 PE 4.68、PB 0.44。

但银行低估值不是免费午餐。市场压低PB，反映的是三件事：

- 净息差下行；
- 地产链和地方债风险最终由谁承担；
- 银行利润增长越来越依赖拨备、手续费、资产质量变化，而不是简单规模扩张。

**为什么终选工商银行？**

1. **系统重要性最高**：大行里更像金融基础设施，分红稳定性优先于利润弹性；
2. **估值仍低**：PE 6.82 对应盈利收益率约 14.66%，PB 0.65；
3. **组合角色清晰**：它不是用来赚成长的钱，而是用来降低组合波动、承接市场防御风格的钱。

建设银行是高度相似的替代品；招商银行商业模式更好但估值和零售风险需要单独研究；兴业银行便宜但地产链、同业和地方融资相关风险更敏感。宁波银行不是坏公司，但本轮主题是“高股息压舱石”，不是城商行成长股，因此淘汰。

### 3.3 公用事业：真正买的是“特许经营资产的久期”，但价格纪律最重要

公用事业里，最好的资产往往不是最高股息率，而是最稳定的长久期现金流。长江电力的核心不是“今天分红有多高”，而是：

- 长江干流水电资产稀缺；
- 单位发电成本低；
- 资产寿命长；
- 现金流可预测性高；
- 资本开支节奏相对清晰。

但它的缺点也很明显：PE 18.44、PB 2.92，在防御资产里并不便宜。它是本轮终选中“业务质量最高，但价格最需要纪律”的标的。

国投电力、华能水电、川投能源都可以观察：国投电力估值更低但资产结构更杂；华能水电和川投能源水电属性强，但规模、来水波动和投资平台折价需要进一步拆；中国广核和中国核电是核电稳定资产，但核电扩张、资本开支和估值都要更细看。

## 4. 第四层：四大师视角终选分析

### 4.1 中国神华：资源股里最像“现金流机器”的公司

> **巴菲特会问**：如果煤价下行，这家公司还能不能靠成本、铁路港口和电力一体化活得很好？

中国神华的优势不在于“煤炭涨价时弹性最大”，而在于它比多数煤炭公司更像一套完整的能源基础设施系统。煤炭贡献利润，铁路和港口稳定运输，电力消化一部分资源，整体形成低成本、强现金流、可分红的闭环。

| 维度 | 判断 |
|---|---|
| 生意质量 | 资源周期股中偏高，一体化降低波动 |
| 护城河 | 资源禀赋、铁路港口、电力一体化、规模成本优势 |
| 管理与分红 | 央企属性，分红纪律强，但也受政策目标影响 |
| 当前估值 | 41.91元，PE 17.63，市值约9,090亿元；按周期股看不算深度便宜 |
| 最大风险 | 煤价中枢下行、长协价格机制变化、政策性让利、资本开支上升 |

**段永平式一句话**：这是“好资产 + 好现金流”，但不能用成长股估值去买资源股。

**本轮结论**：终选第一。适合作为高股息资源核心观察标的，但买入纪律应绑定煤价悲观期、估值回落或股息率重新具备足够吸引力。

### 4.2 长江电力：最好的公用事业资产之一，但不是随便什么价格都能买

> **芒格会问**：这个资产是不是“少数几乎不可复制的好生意”？如果是，市场是不是已经给了太多溢价？

长江电力的商业本质是：用稀缺水电资产，把长寿命、低边际成本、相对稳定的电量变成可分配现金流。它比火电更少受燃料成本波动影响，比普通新能源运营商更少受补贴和消纳波动影响。

| 维度 | 判断 |
|---|---|
| 生意质量 | 极高，长寿命稀缺水电资产 |
| 护城河 | 资源位置、牌照、调度体系、资产寿命、低成本 |
| 管理与分红 | 现金流稳定，分红属性较强 |
| 当前估值 | 27.19元，PE 18.44，PB 2.92，市值约6,653亿元；质量好但估值不低 |
| 最大风险 | 来水波动、电价机制、资产注入价格、利率上行导致防御资产估值压缩 |

**李录式一句话**：长江电力的问题通常不是“会不会消失”，而是“你付出的价格是否允许长期复利”。

**本轮结论**：终选第二。它是高股息/公用事业方向里质量最硬的锚，但当前更适合列为核心观察，不宜因为防御属性而忽视安全边际。

### 4.3 工商银行：不是好故事，但可能是好压舱石

> **巴菲特会问**：这家银行的低估值，是永久性价值陷阱，还是系统重要性资产给长期持有者的补偿？

工商银行不是一个让人兴奋的成长故事。它的价值来自另外一套逻辑：低估值、系统重要性、较强分红纪律、极高流动性，以及在市场风格转向防御时的资金容纳能力。

| 维度 | 判断 |
|---|---|
| 生意质量 | 金融基础设施型资产，成长性弱但稳定性强 |
| 护城河 | 规模、客户基础、低成本负债、系统重要性 |
| 管理与分红 | 大行分红纪律相对强，但也承担政策性金融职能 |
| 当前估值 | 7.11元，PE 6.82，PB 0.65，市值约25,340亿元；盈利收益率约14.66% |
| 最大风险 | 净息差继续下行、资产质量暴露、地产/地方债风险、分红率下调 |

**段永平式一句话**：工商银行不是用来幻想十倍股的，它是用来问“这部分钱我愿意拿多少收益换少一点波动”。

**本轮结论**：终选第三。若组合已有较多科技、医药、资源弹性资产，工商银行可作为低相关度压舱石；但仓位不应过大，因为银行的上行空间通常受ROE和估值中枢约束。

## 6. 估值与操作信号

### 6.1 不是“越高股息越买”，而是三种买法
