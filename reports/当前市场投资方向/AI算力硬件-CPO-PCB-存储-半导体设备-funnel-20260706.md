# AI算力硬件：CPO/PCB/存储/半导体设备行业漏斗筛选报告（2026-07-06）

> **技能**：industry-funnel  
> **研究方向**：AI算力硬件：CPO/光模块、AI PCB、HBM/存储、半导体设备（A股为主，全球龙头作参照）  
> **研究日期**：2026-07-06 22:28（Asia/Shanghai，已用 `Get-Date` 确认）  
> **数据截止**：A股行情为 2026-07-06 收盘后东方财富快照；A股财务数据以东方财富 2025 年报口径为主；海外公司采用截至 2026-07 可获得的官方财报/公开投资者关系材料与公开行情近似口径。  
> **结论一句话**：AI算力硬件不是一个赛道，而是四条不同风险收益曲线：**光模块最景气但估值最挤，PCB是更“卖铲子”的确定性扩产，HBM/存储是全球巨头利润池，半导体设备是国产替代长坡但短期估值不便宜**。本轮终选三家为 **中际旭创（核心）/ 胜宏科技（卫星）/ 北方华创（国产替代长期期权）**；新易盛、沪电股份、SK hynix、Micron、ASML、澜起科技进入高优先级观察。

## 0. 先划边界：本报告筛的是“算力硬件卖铲子”，不是AI应用股

这次主题是 **CPO/PCB/存储/半导体设备**，核心问题不是“谁讲AI故事最动听”，而是：

1. 云厂商资本开支继续上行时，谁的订单先变成收入？
2. GPU/ASIC集群从 800G 到 1.6T、从板级互联到CPO时，谁的单位价值量上升？
3. 如果AI资本开支放缓，谁的利润先塌？
4. 中国投资者能买到的A股公司，哪些是全球链条的真实供应商，哪些只是概念映射？

**主动排除或降级**：

- 纯AI应用、模型、云服务商：商业模式与硬件周期不同，不放进本次前三。
- GPU芯片设计：NVIDIA/Broadcom/AMD/海光/寒武纪很重要，但用户给出的四个子方向不以GPU为主；海光、寒武纪只作为算力硬件景气参照，不作为终选。
- 泛电子制造、消费电子零部件：除非AI服务器/高速网络收入占比已经显著提升，否则只进观察池。

## 1. 行业入口信号：AI集群的瓶颈正在从“芯片”外溢到“互联、载板、内存、制程”

AI集群的经济学很简单：GPU/ASIC越贵，越不能让它等数据。于是系统必须同时补齐四块短板：

| 环节 | AI集群里的作用 | 价值量上升原因 | 最大风险 |
|---|---|---|---|
| CPO/光模块 | 服务器/交换机之间高速传输 | 800G -> 1.6T，端口数和速率提升；硅光/CPO提升技术门槛 | 云厂商资本开支波动、价格下降、客户集中 |
| AI PCB/CCL | 承载高速信号和电源完整性 | GPU板、交换机、AI服务器需要高层数、高频高速、高可靠PCB | 扩产后价格竞争、良率和认证不达预期 |
| HBM/存储 | 给GPU/ASIC喂数据 | HBM容量、堆叠层数、带宽提升；DRAM周期被AI结构性需求重塑 | HBM供给正常化后价格回落 |
| 半导体设备 | 先进制程、先进封装、存储扩产基础 | 国产替代 + 先进封装/HBM/逻辑扩产 | 出口管制、下游晶圆厂资本开支周期 |

### 1.1 产业链地图

```text
GPU/ASIC需求
  -> HBM/DRAM：SK hynix / Micron / Samsung / 澜起科技 / 兆易创新
  -> AI服务器主板与高速PCB：胜宏科技 / 沪电股份 / 深南电路 / 生益科技 / 鹏鼎控股
  -> 数据中心网络：交换芯片 / 交换机 / 800G-1.6T光模块 / 硅光 / CPO
       -> 中际旭创 / 新易盛 / 天孚通信 / Coherent / Lumentum / 源杰科技
  -> 制造端：晶圆设备 / 薄膜沉积 / 刻蚀 / 清洗 / CMP / 量测
       -> ASML / Applied Materials / Lam Research / KLA / 北方华创 / 中微公司 / 盛美上海 / 拓荆科技 / 华海清科
```

### 1.2 这个主题的好生意与坏生意

| 维度 | 好的一面 | 坏的一面 |
|---|---|---|
| 需求 | AI资本开支是真金白银，订单传导快 | 需求高度依赖少数云厂商和NVIDIA/ASIC路线 |
| 护城河 | 高速光模块、AI PCB、HBM和半导体设备都有认证/良率/工艺门槛 | 很多门槛是“阶段性门槛”，不是永久垄断 |
| 财务 | 2025年A股龙头已出现收入、利润、ROE共振 | 高景气年份的利润不能简单外推 |
| 估值 | 资金愿意给AI硬件高估值 | 多数A股已从“低估”进入“定价充分/透支”区间 |
| 投资难点 | 产业趋势清晰 | 真正难的是买入价格和景气拐点识别 |

## 3. 第二层：价值投资硬指标粗筛

### 3.1 粗筛硬指标

本轮设置 5 条硬指标，不追求“便宜”，先排除明显不适合深挖的对象：

1. **真实AI硬件收入/订单相关性**：不是概念映射，必须能解释收入如何受益。
2. **2025财务共振**：收入增长、净利增长、毛利率/ROE至少有一项显著改善。
3. **护城河来源清楚**：客户认证、良率、技术代际、资本开支、规模至少有一项强。
4. **估值没有完全脱离利润**：高PE可以接受，但必须有高增长或高确定性支撑。
5. **景气反转可监测**：能找到订单、价格、CapEx、库存、毛利率等前瞻指标。

## 4. 第三层：精细分析（进入决赛圈的10家公司）

### 4.1 中际旭创：当前A股AI硬件里最像“全球龙头”的公司

中际旭创的核心不是“光模块概念”，而是全球AI数据中心从400G/800G向1.6T升级时，云厂商必须采购的高速数通模块。2025年收入382.4亿元、归母净利108.0亿元，净利率30.3%、ROE 43.8%，这已经不是小票弹性，而是全球级制造龙头的利润表。

**正面**：客户认证、规模交付、良率、供应链管理共同构成护城河。高速光模块不是单纯拼价格，交付失败会拖累整机/集群上线，因此头部供应商有粘性。

**反面**：这也是最拥挤的共识。市值约1.23万亿元，TTM PE 53x，市场已经把未来两三年的高景气部分定价进去。若800G/1.6T价格下降、云厂商CapEx放缓或新竞争者抢份额，估值压缩会很快。

### 4.2 新易盛：弹性强于中际，但容错率更低

新易盛2025年收入248.4亿元，同比增长187.3%；归母净利95.3亿元，同比增长235.9%；ROE高达72.8%。从财务弹性看，它甚至比中际更惊人。

**正面**：在AI光模块放量期，较小基数叠加强订单，会带来非常漂亮的利润弹性。毛利率47.8%、净利率38.5%，说明它不是低端代工。

**反面**：高ROE与高增长往往也是周期高点信号。市场给到约7067亿元市值，容错率比中际更低；一旦客户结构、价格、份额出现扰动，利润和估值会同向回撤。

### 4.3 天孚通信：硅光/CPO方向的上游“镐头”，但赔率变差

天孚通信做光器件和无源器件，受益于高速模块、硅光和潜在CPO升级。2025年毛利率54.0%、ROE 41.9%，财务质量很好。

**正面**：上游器件如果卡住关键工艺，可能比模块环节拥有更高毛利和更强技术壁垒。

**反面**：约2585亿元市值对应PE 131x，已经不是传统价值投资能轻松下手的位置。它更像“技术路线期权”，需要CPO/硅光兑现来消化估值。

### 4.4 胜宏科技：AI PCB里弹性最漂亮的一家公司

胜宏科技2025年收入192.9亿元，同比增长79.8%；归母净利43.1亿元，同比增长273.5%；毛利率35.2%、ROE 35.6%。这说明AI服务器/高速PCB带来的不是简单收入扩张，而是产品结构升级。

**正面**：AI服务器、GPU板、交换机对PCB层数、材料、信号完整性要求提高，龙头公司可以通过认证、良率和产能爬坡获得超额利润。相较光模块，PCB环节的估值虽然也不低，但利润基础更容易被看见。

**反面**：PCB行业历史上供给扩张很快，优秀公司的护城河弱于光刻机/HBM原厂。若同行扩产、客户压价或AI服务器设计变化，毛利率可能回落。

### 4.5 沪电股份：更稳的AI PCB代表

沪电股份2025年收入189.5亿元，同比增长42.0%；归母净利38.2亿元，同比增长47.7%；ROE 28.6%。它的增长没有胜宏夸张，但商业质量更稳。

**正面**：沪电在通信、高速PCB、汽车板等领域积累深，AI服务器和交换机放量能提升产品结构。约49.9x PE相对可解释。

**反面**：如果只看弹性，沪电不如胜宏；如果只看护城河，PCB又不如HBM原厂/半导体设备。它适合做稳健观察，不一定是本轮最锐利的前三。

### 4.6 深南电路：平台型好公司，但AI纯度不如前两家PCB

深南电路有PCB、封装基板、电子装联能力，是A股电子制造平台型公司。2025年收入236.5亿元、归母净利32.8亿元。

**正面**：平台化能力和客户结构优秀，封装基板也可能受益先进封装趋势。

**反面**：PE 88x，对一家收入增速32%、净利率13.9%的公司来说并不便宜。AI硬件纯度与利润弹性不如胜宏/沪电。

### 4.7 澜起科技：A股存储里最接近“高质量服务器升级”的标的

澜起科技2025年收入54.6亿元，同比增长49.9%；归母净利22.4亿元，同比增长58.4%；毛利率62.2%。它不是HBM原厂，而是服务器内存接口芯片公司，受益于DDR5、MRDIMM、CXL等服务器内存升级。

**正面**：高毛利、轻资产、技术门槛明确，比存储模组公司更有护城河。

**反面**：约3284亿元市值，PE 96.9x，市场已经把服务器内存升级给了很高估值。若新品节奏或服务器平台切换不及预期，估值难撑。

### 4.8 SK hynix：HBM主线的全球核心，但不是A股可直接替代品

SK hynix是HBM最核心的全球玩家之一，AI GPU/ASIC需要高带宽内存，HBM的客户认证、良率、堆叠封装、产能规划都构成强护城河。

**正面**：HBM比普通DRAM更难、更紧缺、更绑定客户。若AI集群继续扩张，SK hynix是最直接的利润池之一。

**反面**：内存终究有周期属性。三年后若HBM供给正常化，价格和利润率可能从高位回落。投资它本质上是在买“HBM高景气持续时间”。

### 4.9 Micron：美国本土HBM二供期权

Micron是美国内存龙头，受益于美国本土供应链安全和HBM份额提升。相较SK hynix，它可能不是当前最强，但赔率来自“从第三梯队向第二梯队爬升”。

**正面**：如果NVIDIA/AMD/云厂商需要多元化HBM供应，Micron的战略价值上升。

**反面**：它仍暴露于DRAM/NAND周期，HBM份额和良率提升需要持续验证。

### 4.10 北方华创：国产半导体设备平台型龙头

北方华创2025年收入393.5亿元，同比增长30.9%；归母净利55.2亿元，同比小幅下降1.8%；毛利率40.1%。它不是短期AI订单最直接受益者，而是中国半导体设备国产替代的主线资产。

**正面**：平台化设备公司稀缺，刻蚀、薄膜沉积、清洗等环节都受益国产替代。AI芯片、HBM、先进封装长期都离不开设备能力。

**反面**：约5832亿元市值、PE 89x，而2025净利没有增长，短期估值压力明显。它更适合做长期核心观察/分批配置，而不是追涨买入。

## 5. 第四层：四大师视角终选3家

### 5.1 终选一：中际旭创（核心）

**一句话本质**：中际旭创卖的是AI集群里“让昂贵GPU不空转的高速数据通道”。

| 视角 | 判断 |
|---|---|
| 巴菲特 | 财务结果最像好生意：2025净利108亿、ROE 43.8%、净利率30.3%，但安全边际来自价格而非故事 |
| 芒格 | 护城河来自客户认证、良率、规模交付和供应链协同；但技术代际会持续要求再投资 |
| 段永平 | 好公司可以看懂：客户为什么付钱、产品为什么升级、利润为什么爆发都清楚；难点是“好价格” |
| 李录 | 最大风险不是看错AI方向，而是把高景气利润当永续利润；必须跟踪价格、客户CapEx和库存 |

**为什么进前三**：它是本轮主题里收入、利润、全球地位最清晰的A股龙头；相比上游器件期权，订单兑现更直接；相比PCB，技术代际和客户认证壁垒更强。

**反面论证**：2026年市值已经约1.23万亿元，按2025净利粗算静态市盈率约113.5x；东方财富TTM PE 53.4x说明市场在快速计入后续增长。若未来利润增长放缓，估值压缩会非常痛。光模块单价有下降压力，行业高利润率不一定长期保持。

**投资动作**：空仓不建议追涨一次性买入；等待20%-30%回撤或季度订单继续超预期后分批。持仓可作为AI硬件核心仓，但需要设置景气监控线。关键监控：800G/1.6T出货、毛利率、前五大客户占比、存货/应收、云厂商CapEx。

### 5.2 终选二：胜宏科技（卫星）

**一句话本质**：胜宏科技卖的是AI服务器和高速网络里更复杂、更高价值量的PCB底座。

| 视角 | 判断 |
|---|---|
| 巴菲特 | 财务弹性极强：2025净利增长273.5%，ROE 35.6%；但要确认不是周期高点 |
| 芒格 | 护城河弱于光模块龙头和半导体设备平台，但认证、良率、产能爬坡仍构成阶段性优势 |
| 段永平 | 生意比芯片简单，需求路径容易理解；问题是行业扩产后谁还能赚钱 |
| 李录 | 最大风险是把产品结构升级误判为永久毛利率提升；必须盯同行扩产和价格 |

**为什么进前三**：AI PCB是本轮AI硬件中确定性很高但讨论热度略低于光模块的环节；胜宏2025年的收入、利润、ROE共振最强，说明其受益不是概念层面。作为卫星仓，它提供比中际更高的利润弹性，但不应承担核心仓权重。

**反面论证**：PCB行业长期竞争格局不如HBM/设备稀缺，扩产后毛利率可能下行。市值约2877亿元，按2025净利粗算静态PE约66.7x，已不便宜。

**投资动作**：只在回撤或盈利上修能覆盖估值时买；持仓作为AI硬件卫星仓更合适，仓位低于中际。关键监控：AI服务器板收入占比、毛利率、产能利用率、大客户认证、资本开支。

### 5.3 终选三：北方华创（长期期权）

**一句话本质**：北方华创卖的是中国半导体产业链“不得不自己掌握”的设备能力。

| 视角 | 判断 |
|---|---|
| 巴菲特 | 不是眼前最便宜，但行业位置稀缺；需要用长期现金流而非一年利润判断 |
| 芒格 | 平台型设备公司的学习曲线、工艺积累、客户验证构成长期复利护城河 |
| 段永平 | 能看懂的是国产替代需求，不容易看懂的是每个设备环节的技术差距和订单节奏 |
| 李录 | 最大风险来自政策/出口管制/晶圆厂资本开支周期；但反过来这些也是国产替代加速器 |

**为什么进前三**：用户主题包含半导体设备；如果只选光模块和PCB，会错过“AI硬件国产基础设施”的长期主线。北方华创比单一设备公司更平台化，抗单品波动能力更强。它不是最锐利的短期AI弹性，但可能是未来5-10年国产半导体设备的核心资产。

**反面论证**：2025净利55.2亿元，同比小幅下降，而市值约5832亿元，静态估值压力大。半导体设备订单与晶圆厂CapEx强相关，若国产晶圆厂投资节奏放缓，利润兑现会慢。

**投资动作**：更适合“长期跟踪 + 大跌分批”，不是追AI硬件情绪。持仓可作为硬科技底仓，但要接受短期估值波动。关键监控：新签订单、合同负债、存货、毛利率、先进制程/先进封装设备进展、出口管制变化。

新易盛非常优秀，但它和中际同属光模块主线。为了避免组合在单一环节过度集中，前三只保留一个光模块核心。若只做“光模块子赛道”，新易盛应进入前三，甚至可以和中际并列核心。

**为什么没有把SK hynix/Micron放进前三？**  
它们是HBM主线最优质资产，但本报告以A股可执行为主。若允许全球组合，SK hynix应替换北方华创进入前三，Micron进入观察/卫星。

## 8. 整体行业位置判断

| 子赛道 | 阶段 | 判断 |
|---|---|---|
| 光模块/CPO | 扩张中后段 | 订单仍强，但A股估值已反映高景气，重点看1.6T/CPO兑现 |

**当前估值态度**：几乎所有核心A股AI硬件公司都已经被资金重估；但中际/新易盛/胜宏的利润确实在兑现，不能简单说“只有概念”。最危险的错误是把2025-2026高景气利润线性外推到2030年。更合理的打法是“核心龙头 + 卫星弹性 + 长期设备底仓”的组合，而不是押单一最热环节。

## 13. 最终判断

如果只能在“AI算力硬件”里选一个A股核心，**中际旭创**最符合“趋势强、兑现快、全球地位清晰”的要求；如果想要更高弹性，**胜宏科技**是AI PCB里最值得深挖的卫星；如果把时间拉到5-10年，**北方华创**代表的是中国半导体设备国产替代的长期底座。

但当前不是“闭眼买AI硬件”的阶段。2025年利润已经爆发，2026年股价也已大幅重估。真正的纪律是：**承认产业趋势，拒绝用任意价格买趋势。**
