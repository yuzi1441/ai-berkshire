# 国药现代（600420.SH）行业与竞争维度报告：医药制造/化学制药/集采周期

**角色**：industry-researcher（芒格视角：先找行业坏生意特征，再看公司是否有少数抵抗机制）  
**研究日期 / 数据截止**：2026-07-08  
**信息丰富度评级**：A 级（上市公司年报、医保局/统计局/政策文件充足；主要风险是“资料太多导致共识化叙事”，需重点反面检验）  
**范围说明**：本报告只交付行业与竞争维度，不构成最终投资建议。

---

## 3-5 条核心结论

1. **化学制药的主问题不是需求消失，而是支付方把行业利润重新切走。** 2025 年全国规模以上医药制造业营业收入约 2.49 万亿元，同比 -1.2%；利润总额约 3490 亿元，同比 +2.7%。行业不是高增速扩张期，而是“收入低速/负增长 + 企业分化 + 成本效率决定生死”的成熟期。
2. **集采进入制度化、反内卷化阶段，但这不是价格权回归。** 第十一批国家集采覆盖 55 种药品、272 家企业 453 个产品拟中选，国家医保局强调“稳临床、保质量、反内卷、防围标”。这可能降低极端低价扰动，却不会改变成熟仿制药长期被医保控费的方向。
3. **国药现代的产业链一体化是防御性优势，不是天然进攻性护城河。** 2025 年公司原料药及中间体收入 44.76 亿元、制剂收入 46.22 亿元，二者合计接近主体业务全部；但两个板块收入均两位数下滑，说明一体化能缓冲成本和供应风险，却不能自动抵消终端降价和原料药过剩。
4. **竞争胜负正在从“谁有批文/谁进医院”转向“谁能在低价、合规、稳定供应、规模制造下还有合理回报”。** 对国药现代而言，国药集团平台、抗感染产业链、国际注册、156 个一致性评价/视同通过项目是生存资源；但在特色专科药和创新升级上，仍面临恒瑞、齐鲁、正大天晴、石药、科伦等更强研发/商业化对手。
5. **非共识观察：成熟化药可能越来越像“公共事业型制造业”。** 份额会向央国企和成本领先者集中，但行业回报率未必同步上升；好公司不等于好行业，行业出清后的赢家也可能只是获得更稳定、更低波动的现金流，而非高估值成长逻辑。

## 一、行业规模与增长：需求刚性，但增长被支付约束“压扁”

| 维度 | 现状 | 对化学制药/国药现代的含义 | 反面检验 |
|---|---:|---|---|
| 医药制造业规模 | 2025 年规模以上医药制造业营业收入约 24,870 亿元，同比 -1.2%；利润总额约 3,490 亿元，同比 +2.7% | 行业仍大，但已不是普涨阶段；利润改善可能来自成本、结构和低基数，不等于需求强复苏 | 若只看“老龄化 + 刚需”，会误判为自然高成长行业 |
| 医保支付能力 | 2025 年基本医保基金总收入约 35,873 亿元、总支出约 30,009 亿元，参保人数约 13.31 亿、参保率约 95% | 最大支付方仍有规模，但控费纪律强；药企不能简单把需求增长转化为价格权 | 医保基金有结余不代表愿意提高成熟仿制药价格 |
| 化学仿制药周期 | 一致性评价、集采、医保目录、挂网价格联动共同塑造行业利润 | 通过评价/视同通过成为入场券，不再是超额利润来源 | 通过一致性评价数量多，反而可能带来更多同质化竞争 |
| 国企改革 | 央国企平台整合、亏损治理、供应保障导向增强 | 国药现代作为国药集团化学制药工业平台，有整合和资源协同空间 | 平台地位若不能转化为 ROIC 改善，只是叙事资产 |

### 政策周期判断

- **集采**：已从一次性冲击进入常态化续约与扩围。第十一批强调反内卷、保质量、提高投标资质门槛，意味着监管希望避免“低价低质”破坏供应，但成熟品种价格中枢仍由医保和招采规则决定。
- **一致性评价**：早期是门槛红利，后期是竞争标准化工具。通过者越多，单品价格和利润越容易被压平。
- **医保控费**：基金覆盖面极广，医保更像行业的“集中采购经理”。它保障需求，也压缩药企对终端的议价能力。
- **国企改革**：对国药现代的积极面是资产整合、亏损治理、工商协同；负面检验是央企平台不自动产生产品差异化，最终仍要回到品种、成本、质量和效率。

## 二、竞争格局：国药现代在哪里？

### 2.1 化学制剂 / 原料药 / 特色专科药竞争表

| 赛道 | 行业经济特征 | 主要玩家 | 国药现代位置 | 芒格式判断 |
|---|---|---|---|---|
| 大宗化学制剂/成熟仿制药 | 规模大、同质化强、集采价格约束强；渠道和生产稳定性重要 | 国药现代、华润双鹤、科伦药业、齐鲁制药、扬子江、石药、正大天晴等 | 重点在抗感染、心血管、神经系统等；2025 年制剂收入 46.22 亿元，毛利率 42.06%，但收入同比 -15.21% | 这是“低差异化 + 强支付方”的赛道，除非成本领先或品牌/剂型有差异，否则不是天然好生意 |
| 原料药及医药中间体 | 国际注册、环保安全、工艺路线、规模制造有门槛；但部分抗生素 API 产能过剩 | 国药现代、普洛药业、华海药业、海普瑞、九洲药业、天宇股份等 | 2025 年该板块收入 44.76 亿元，毛利率 24.71%，公司称产销量增长但价格明显下降 | 一体化是护栏，不是城堡；若外部 API 价格下行，内部自产未必带来超额利润 |
| 特色专科药/复杂制剂 | 研发、临床价值、准入、医生认知、剂型壁垒更重要 | 恒瑞医药、齐鲁制药、正大天晴、石药、科伦、丽珠、华东医药等 | 公司布局麻醉及精神、抗肿瘤及免疫、代谢内分泌，并推进缓控释、膜剂等平台，但主收入仍偏成熟品种 | 若没有临床差异化，复杂剂型也可能被复制和集采；真正壁垒来自“难仿 + 强临床需求 + 可持续商业化” |
| 国际化仿制药/API | FDA/欧盟/WHO 等认证提升准入门槛，但国际价格竞争同样激烈 | 华海、普洛、国药现代、齐鲁、复星医药、印度仿制药企业等 | 公司产品出口 70 余个国家和地区，部分 API/制剂拥有 FDA、欧盟、WHO 等认证；2025 年新增境外注册证 12 项 | 国际注册提高下限，但印度和中国同行共同竞争，不能简单等同于高毛利国际化 |

### 2.2 国药现代相对位置

| 指标 | 国药现代 2025 年情况 | 竞争含义 |
|---|---:|---|
| 营业收入 | 93.63 亿元，同比 -14.39% | 规模处于 A 股化药中等偏大，但增长承压明显 |
| 归母净利润 | 9.42 亿元，同比 -13.11% | 仍有盈利韧性，但不是景气上行状态 |
| 原料药及中间体 | 收入 44.76 亿元，占收入 47.81%；毛利率 24.71%，同比下降 9.15pct | API 价格压力非常真实；一体化不能免疫周期 |
| 制剂 | 收入 46.22 亿元，占收入 49.36%；毛利率 42.06%，同比下降 3.66pct | 制剂毛利率高于 API，但集采和竞争正在侵蚀 |
| 一致性评价/新批文 | 累计通过一致性评价项目（含视同）156 个；新产品批准文号 64 个 | 批文矩阵丰富，有入围能力；但也说明公司处在高度标准化仿制药战场 |
| 集采表现 | 第十一批国家集采 6 个品种中选 | 有助于保份额；但“中选”通常意味着以价格换量，而非恢复定价权 |
| 国药集团协同 | 国药集团化学制药工业平台，和国药控股、国药医工总院等存在工商/工研协同 | 资源和渠道是优势；真正要观察协同是否改善费用率、库存周转、亏损子公司治理 |

## 三、产业链价值分配：价值更多流向支付方和真正差异化环节

| 产业链环节 | 参与者 | 价值捕获能力 | 关键变量 | 对国药现代的意义 |
|---|---|---:|---|---|
| 上游基础化工/中间体 | 基础化工、发酵、酶法/合成路线供应商 | 中低，受原材料、环保、安全、产能周期影响 | 成本、环保合规、稳定供应 | 原料药一体化能降低断供风险，但大宗品价格下行会传导到利润 |
| 原料药/API | API 厂、特色原料药企业、国际注册企业 | 分化：特色 API 中高；大宗 API 中低 | DMF/CEP/FDA、工艺收率、客户审计、产能利用率 | 国药现代在抗感染 API 有规模与认证，但抗生素链条面临产能和价格周期 |
| 制剂制造 | 仿制药/复杂制剂/品牌普药企业 | 普通仿制药中低；复杂制剂和专科药中高 | 一致性评价、剂型难度、成本、集采中选、渠道覆盖 | 公司制剂毛利率仍高于 API，但成熟品种受集采和同质化压制 |
| 医药流通 | 国药控股、华润医药商业、上海医药等 | 低利润率但强周转、强网络 | 配送资格、账期、终端覆盖、资金效率 | 国药集团内协同可改善准入和配送，但不能改变药价规则 |
| 医院/零售/线上 | 公立医院、基层医疗、连锁药店、电商平台 | 医院掌握处方与用量，医保/集采掌握价格；零售可承接部分品牌慢病需求 | 处方外流、双通道、线上诊疗、院内目录 | 国药现代品牌慢病药有零售延伸空间，但处方药核心仍受医保与招采约束 |
| 医保/集采组织 | 国家医保局、省级招采联盟 | 最高议价权 | 报量规则、续约规则、医保目录、基金预算 | 这是行业最强“客户”；企业需要适应而非对抗 |

**一句话**：普通化药产业链中，最终价值越来越不像传统品牌药那样留在药企，而是被医保、医院采购和低成本制造效率重新分配。药企能留下的超额利润，来自难仿技术、规模成本、质量信用、供应稳定和少数仍有品牌/临床差异化的品种。

## 四、技术变革和政策影响

| 变化 | 方向 | 利好谁 | 对国药现代的检验点 |
|---|---|---|---|
| 高端复杂制剂、缓控释、膜剂等剂型升级 | 从普通仿制走向难仿、改良型 | 有研发平台、工艺放大、注册能力的企业 | 公司披露推进缓控释、膜剂平台；要看新产品收入能否弥补大品种下滑，而不是只看获批数量 |
| 医药工业数智化 | 研发、生产、质量、供应链和营销数字化 | 规模企业、合规要求高的央国企平台 | 是否降低制造成本、库存和质量风险；若只是信息化投入，则不是护城河 |
| 集采规则优化 | “反内卷、保质量、稳临床” | 质量体系好、供应能力强、报价理性的企业 | 有利于国药现代这类规模厂保份额，但仍要求成本纪律 |
| 创新药和临床价值导向政策 | 支持真正创新和临床急需产品 | 恒瑞、百济、信达、科伦创新药、齐鲁/正大天晴等强研发企业 | 国药现代若停留在成熟仿制药，将享受不到政策上行红利 |
| “四同政策”与替代规则 | 同通用名、同剂型、同规格、同厂家/非同厂家替代环境更强 | 价格低、质量可证明、供应稳的企业 | 品牌溢价下降；对神经系统等部分品种收入形成压力 |

## 五、竞争威胁与替代风险

| 风险 | 机制 | 影响对象 | 观察指标 |
|---|---|---|---|
| 集采续约继续压价 | 中选后续约、地方联盟采购、挂网价联动 | 成熟制剂大品种 | 中选价格、续约降幅、销量是否补足价格损失 |
| API 产能过剩 | 产销量增长但价格下降，毛利率被压缩 | 抗感染 API、部分中间体 | API 板块毛利率、库存、产能利用率、出口单价 |
| 特色专科药被更强研发企业抢占 | 创新药、改良型新药和复杂制剂替代普通仿制药 | 抗肿瘤、代谢、神经、麻醉等 | 新产品收入占比、临床价值、是否进入医保但仍保留利润 |
| 抗感染用药需求结构变化 | 抗菌药物管理、院感控制、头孢需求疲软 | 公司抗感染制剂和抗生素产业链 | 头孢类销量/单价、市占率提升是否能带来利润提升 |
| 国企协同效率不达预期 | 平台资源多但内部治理、亏损主体、两金占用拖累 | 整体 ROIC 和现金流 | 亏损子公司数量、资产处置、应收账款、存货周转 |
| 国际市场价格竞争 | 印度和中国仿制药/API 企业共同竞争，海外审计趋严 | 出口 API/制剂 | FDA/CEP/WHO 认证延续、海外注册转化收入、出口毛利率 |

## 七、资料充裕下的非共识观察

1. **不要把“国药集团化药平台”直接翻译成护城河。** 平台能带来供应链、渠道、研发协同和资产整合，但普通化药真正的护城河仍是单品成本曲线、质量稳定性、供应韧性和少数剂型壁垒。
2. **集采“反内卷”不是药企重新涨价的信号，而是监管希望行业别被极端低价打坏。** 对国药现代这类规模厂，它更像“减少恶性竞争尾部风险”，不是“恢复高毛利”。
3. **公司 2025 年“销量增长但价格下降”的 API 描述很关键。** 这说明需求量并非完全坏，但行业利润池被产能和价格竞争稀释。芒格视角下，这比单纯收入下降更值得警惕：忙得更多，不一定赚得更多。
4. **制剂毛利率仍高，但大品种收入下滑说明成熟制剂的经济性在被重新定价。** 心血管以价换量、抗感染市占率提升，是份额逻辑；要形成利润逻辑，必须证明规模效应能覆盖降价。
5. **成熟化药的赢家可能是“低波动供应保障型现金流”，而不是高成长资产。** 如果未来行业集中度提升，最可能先改善的是出清后的稳定性，而不是快速恢复高 ROE/高估值。
