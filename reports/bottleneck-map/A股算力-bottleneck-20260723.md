# A股算力供应链瓶颈研究报告

**研究日期**：2026-07-23  
**数据截止**：行业事件截至 2026-07-22；A股价格、市值为 2026-07-23 行情快照；财务以 2025 年报为统一口径。  
**研究范围**：A股可交易的算力芯片、光互联、PCB/材料、液冷、供配电与服务器制造。  
**一句话结论**：A股算力最硬的物理瓶颈是先进封装、InP/CW/EML 激光器、低损耗玻纤布和电力设备，但前三者缺少“纯正且便宜”的A股映射；当前更值得深研的是估值尚可、业绩已兑现的工业富联，以及间接受益电网扩容的华明装备，真正坐在材料或光芯片咽喉上的公司反而普遍没有安全边际。

> 这份报告用于学习与研究，不构成投资建议。价格会变，瓶颈也会被扩产和技术替代解除。

## AI研究偏见自觉

| 偏见 | 本次风险 | 处理 |
|---|---|---|
| 热门股偏见 | 算力搜索结果被寒武纪、海光、中际旭创占据 | 强制拆到材料、部件与设备层 |
| 国产替代偏见 | 把“买不到海外芯片”直接等同于国产公司盈利 | 分开验证交付、软件生态、产能和估值 |
| 叙事外推 | 把训练缺卡外推成所有推理和数据中心都缺算力 | 只承认有订单、收入和物理交期支持的环节 |
| 估值失明 | 用高增速覆盖100倍以上PS | 执行PS/PE红黄灯和10年25xPE退出检验 |
| 纯度误判 | 把电网、冷却或普通PCB全部贴成AI | 要求瓶颈业务收入占比超过30%，否则降级为间接敞口 |

**信息丰富度**：高。  
**共识陷阱**：行业趋势高度一致，争议集中在价格已经透支多少，而不是需求是否存在。

1. **2026-03-24**：BloombergNEF称2026年头部数据中心运营商资本开支接近7500亿美元，全球在建IT容量超过23GW。

**趋势确认**：可追踪。需求是真实的，问题是利润池位于哪里，以及股票价格是否已把未来兑现完。

## 第二步：物理供应链拆解

```text
Layer 0：模型训练、推理、云服务
  ↓
Layer 1：GPU/ASIC/DCU、HBM、AI服务器、超节点、数据中心
  ↓  热门、定价充分
────────────────────────────────────────
  ↓  瓶颈重点区
Layer 2：CoWoS/先进封装、高速光模块、AI PCB、高速CCL、UPS/HVDC、CDU
  ↓
Layer 3：InP衬底、CW/EML激光器、T-glass/Low-Dk玻纤布、HVLP铜箔、
         分接开关、UQD快接头、探针卡与封装设备
  ↓
Layer 4：电网接入、变压器、发电、土地、水与工程许可
```

**价值捕获顺序**：缺的材料/部件先拿到定价权；整机厂收入弹性更大，但扩产更快、议价权取决于上游配给和客户集中。

### 最近变化

- **先进封装未解除**：TSMC 7月电话会仍称后端短缺，不能用“CoWoS持续扩产”直接推导供需已宽松。
- **光瓶颈继续上移**：Lumentum 2026财年Q3收入同比+90%，Coherent仍在加速扩建InP；瓶颈是激光器和晶圆，不是普通模块装配。
- **低损耗玻纤仍是隐形S级**：TrendForce称Nittobo新增产能有效释放最早到2027年中。
- **液冷评级不升S**：UQD和CDU存在认证与供给约束，但整机和冷板供应商扩张快，A股多数公司坐在集成层而非最窄咽喉。
- **电力瓶颈持续**：美国能源部称大型变压器交期达到3-4年；但华明装备对AI数据中心的直接收入量级较小，主要是电网扩容的间接受益。

## 第五步：重点机会一页纸

### 华明装备（002270）— 瓶颈最硬、估值最便宜，但不是高纯度AI股

**为什么是瓶颈**：分接开关是35kV以上电力变压器必需的调压组件，也是变压器中唯一带负荷动作的部件。公司H股申请材料引用弗若斯特沙利文：全球前三家收入份额82.5%，华明全球第二、份额17.9%，中国份额80%。

**为什么是这家公司**：2025年电力设备收入占86.63%，细分壁垒和收入纯度都高；PS 6.79x、PE 23.23x，是候选中唯一同时满足“PS<10、PE<30、有护城河”的公司。

**反面证据**：公司明确表示，AI数据中心直接使用的分接开关量级较小，真正逻辑是数据中心用电倒逼电网扩容；美国并网项目还存在中国设备准入风险。2026Q1电力设备收入同比-1.28%，没有出现AI订单爆发。

**安全边际**：乐观假设10年净利3倍、25xPE退出，年化+12.44%；达到10%年化需10年后净利17.11亿元，为2025年的2.41倍。

**结论**：值得按“全球电网升级”执行深入研究，不应按高弹性算力股追价。

### 工业富联（601138）— 不是瓶颈，但可能是风险收益比更好的兑现载体

**为什么值得看**：2025年云计算收入6026.79亿元，占总收入66.75%，同比+88.70%；云服务商AI服务器收入增长超过3倍。PS 1.38x、PE 35.36x，显著低于芯片和光模块热门股。

**为什么不是瓶颈股**：服务器ODM和机柜整合供应商较多，扩产周期短于晶圆、激光器和材料；公司的优势是规模制造、客户协同和交付，不是不可替代的单点物料。

**主要风险**：经营现金流2025年同比-78.01%，原因包括扩产和备货；客户集中、低毛利制造属性、AI资本开支放缓都会压缩回报。

**安全边际**：乐观假设10年净利4倍，年化+10.95%；达到10%年化需净利1294.59亿元，为2025年的3.67倍。

**结论**：值得做公司级深研，重点核验现金流、客户集中和AI服务器毛利，而不是把它列为S级瓶颈。

### 科华数据（002335）— 供配电纯度够，估值不贵，但增长尚未验证

**为什么是候选**：2025年智算中心收入35.23亿元，占43.17%；产品覆盖UPS、HVDC、电力模组、PDU、液冷POD。公司披露与互联网客户联合开发的弹性直流一体柜已交付超过2000台。

**为什么只给A-/★★★**：高密UPS和供配电确实受益于机柜功率上升，但供应商不止三家，普通UPS并非单点故障；2025收入仅+5.20%，增长尚未体现强瓶颈租金。

**安全边际**：乐观假设10年净利5倍，年化+8.47%；达到10%需净利24.05亿元，为2025年的5.75倍。

**结论**：观察2026中报的智算中心收入、UPS毛利率和经营现金流；未验证前不升为★★★★。

### 沪电股份（002463）— 高阶产能紧，价格仍要求高增长

**为什么是瓶颈**：2025年数据通讯PCB收入146.56亿元，占总收入77.36%；其中高速交换机/路由81.69亿元，AI服务器/HPC 30.06亿元。公司明确表示高阶产能建设和爬坡存在周期，当前高阶产能偏紧。

**为什么不是S级**：PCB厂可以扩产，客户也会推动多源化；真正更难复制的是上游玻纤布、HVLP铜箔和材料认证。

**安全边际**：PS 11.76x、PE 58.27x；乐观假设10年净利5倍，年化+7.93%。若2025利润不变，PE回到35-45x对应约70-89元，仅作为估值观察尺，不是目标价。

**结论**：好公司、黄灯价格。等待估值回落或高端产能连续两个季度贡献利润。

### 新易盛（300502）— 增长最强，但整机不是最窄咽喉

**为什么是候选**：2025年光互联收入占99.72%，收入+187.29%、净利+235.89%，高速产品需求已进入报表。

**反面证据**：光模块整机受制于上游InP/CW/EML、存储与ASIC；装配产能扩张快，长期毛利取决于客户议价和上游供应。96.16%收入来自境外，客户和地缘风险高。

**安全边际**：PS 27.91x、PE 72.74x；用10年净利8倍的偏乐观假设，年化+10.64%，仅略过门槛。

**结论**：列入高增长观察，不追高；若后续增速跌破100%而PS仍接近30x，按技能规则转红灯。

## 第七步：交叉验证与最强反方

### 正向验证

| 项目 | 结果 | 证据 |
|---|---|---|
| 资本开支 | 通过 | BNEF 2026年约7500亿美元 |
| 先进制程/封装 | 通过 | TSMC Q2收入/HPC占比与电话会短缺表述 |
| 光激光器 | 通过 | Lumentum收入+90%；Coherent扩建InP并称需求强 |
| 材料 | 通过 | TrendForce与Nittobo扩产计划均显示2027年前约束 |
| 电力 | 通过 | DOE大型变压器3-4年交期；GEV数据中心订单翻倍 |
| A股收入 | 通过但分化 | 11家公司2025年报；光互联/PCB已兑现，供配电增长较弱 |

### 最强反方

1. **AI资本开支不等于股东回报**：折旧、融资、客户议价和高估值会吞掉产业增长。
2. **扩产正在发生**：Coherent计划2026年底将内部InP产出翻倍、2027年再翻倍；Nittobo新产能2027年释放，当前短缺可能在2027-2028转为供给宽松。
3. **模块和冷板最容易被错当瓶颈**：供给多、扩产快，真正稀缺的是上游激光器、玻纤、UQD和认证。
4. **国产芯片的瓶颈也可能是有效需求与软件生态**：名义出货不等于可稳定训练，必须跟踪复购、利用率和现金回款。
5. **华明装备不是AI纯度股**：直接数据中心收入未单列且公司称量级小，不能用AI估值给电网设备重新定价。

**最可能的分析错误**：把2025-2026的异常高增速外推十年。估值表已经用偏乐观倍数，仍有多数公司无法达到10%年化。

| 标的/环节 | 动作 | 验证点 |
|---|---|---|
| 工业富联 | 执行公司级深入研究 | AI服务器毛利、经营现金流、客户集中、资本开支 |
| 华明装备 | 按全球电网升级深研 | 海外订单、美国准入、2026Q1后电力设备增速 |

| 新易盛 | 高增长观察 | 增速是否保持>100%、客户集中、上游激光供应 |
| 生益科技 | 不追高 | M8/M9材料收入和毛利、PE消化 |
| 源杰科技 | 暂不追踪价格，只跟踪产业 | CW/EML产能、客户、收入先追上市值 |
| 寒武纪/海光 | 不因国产替代追价 | 交付、经营现金流、生态复购和估值 |

**最终判断**：A股算力是“真趋势、真瓶颈、贵映射”。当前没有同时满足“S级瓶颈 + 高纯度 + 估值绿灯”的明确买点。最合理的下一步不是追最热门的芯片或光模块，而是深研工业富联的兑现质量、华明装备的电网升级逻辑，并等待材料/PCB/供配电标的用利润或价格提供安全边际。
