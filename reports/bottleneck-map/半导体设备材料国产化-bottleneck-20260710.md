## 1. 超级趋势确认

```text
趋势名称：半导体设备/材料国产化（半导体再工业化的中国本土链条）
核心驱动力：外部出口限制 + 中国晶圆厂资本开支 + 供应链安全，使设备/材料“能不能国产替代”从成本问题变成产线可用性问题。
已发生验证事件：
  1. 2026-04-07 SEMI报告：2025年全球半导体制造设备销售约1,351亿美元，同比增长15%。
  2. 2025年SEAJ/SEMI区域数据：中国大陆设备销售约493亿美元，仍是全球最大单一市场之一。
  3. SEMI材料市场数据：2025年全球半导体材料市场收入约732亿美元，同比增长6.8%。
  4. 本地A股F10快照：北方华创/中微/拓荆/盛美/华海等设备公司2025收入已是几十亿到数百亿人民币级，国产替代不是PPT阶段。
资本开支规模：全球设备销售约1,351亿美元/年；中国大陆约493亿美元/年。
供需缺口判断：设备/材料整体不是全面缺货，真正缺口集中在光刻、量测、高端材料、关键零部件和客户验证能力。
趋势确认：✅ 可追踪，但必须用估值门槛过滤。
```

### 1.1 直接结论

- **S级瓶颈**：高端光刻、先进量测检测。这两个环节最卡，但A股可投纯标的弱，更多是整条国产化链条的“系统总开关”。
- **A级瓶颈**：刻蚀/沉积、CMP设备与耗材、高端光刻胶/前驱体/电子特气。这里既有真实国产替代，也有A股上市公司可跟踪。
- **可投资性悖论**：越是真瓶颈，往往越贵、越难买到纯标的；当前 2026-07-09 快照下，多数设备/材料股 PE>80 或 PS>30，按技能规则必须降级。

### 最近变化 vs 上次扫描

- **新增主题扫描**：把“半导体设备/材料国产化”从泛半导体叙事拆成 7 个物理瓶颈。
- **估值状态变化**：A股设备/材料核心公司 2026-07-09 多数处在高估值区，按技能规则信号强度被压低。
- **结论变化**：不是“找最卡的环节就买”，而是“找瓶颈真实、收入已验证、估值未透支的少数公司”。当前这一组合很少。

- **关键数据**：市值 2,352亿元 / 2025收入 65.2亿元 / PS 36.1x / PE(TTM) 147.1x / 收入增速 58.9% / 毛利率 35.0%。
- **估值安全边际检验**：若要求当前买入后10年获得10%年化、2036年以25x PE退出，2036年需净利约 244.0亿元；相当于2025净利的 26.3倍，净利CAGR需 38.7%。结论：**无安全边际**。
- **催化剂时间线**：近期看中报/订单/验收；3-12月看国内晶圆厂新线导入比例、SEMI设备数据、客户现金流。
- **主要风险**：估值透支；国产替代被市场提前定价；客户验收延迟；关键零部件/出口管制反噬。
- **建议**：加入卫星观察，等PS降至合理区。


### 精测电子（300567）— 量测检测/面板与半导体测试

- **为什么是瓶颈**：量测检测/面板与半导体测试处在Layer 2-3，供应商验证周期长，工艺稳定性/良率责任重；国产化需求真实，但不能自动等同于买点。

- **关键数据**：市值 675亿元 / 2025收入 33.5亿元 / PS 20.2x / PE(TTM) 953.8x / 收入增速 30.5% / 毛利率 46.7%。

## 6. 反向验证：聪明人为什么不买？

| 反向问题 | 本主题答案 | 投资含义 |
|---|---|---|
| 这个瓶颈能被绕过吗？ | 光刻/量测很难绕过；成熟制程可用工艺妥协，但先进节点绕不过。部分材料可多供应商验证。 | 真瓶颈主要在S/A级环节，但不等于所有相关股票都能赚钱。 |
| 中国玩家能不能很快复制产能？ | 设备复制慢，材料验证慢；但清洗、部分湿法、部分耗材会逐步竞争加剧。 | 早期高毛利可能被后来者和客户压价削弱。 |
| 终端需求放缓50%会怎样？ | 晶圆厂会推迟验收和资本开支，设备收入确认波动大；材料相对更稳但也受稼动率影响。 | 设备股比耗材股更周期。 |
| 当前估值隐含什么增长？ | 多数公司需要未来十年净利保持十几到二十几的年化增长，且2036年仍能25x退出。 | 当前价格安全边际不足。 |
| 有没有关键零部件反噬？ | 国产设备仍依赖部分真空、射频、传感、运动控制、光学等高端零部件。 | 国产设备自身也有上游瓶颈，利润可能被零部件约束。 |
| 管理层/融资风险？ | 高估值行业容易在景气高点融资扩产，若需求放缓会形成产能与摊销压力。 | 需要逐季跟踪资本开支、存货、应收和现金流。 |
