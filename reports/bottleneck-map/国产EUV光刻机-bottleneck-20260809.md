# 国产 EUV 光刻机供应链瓶颈研究报告

> **数据截止**：2026-08-09（Asia/Shanghai，已用系统 `date` 确认）  
> **行情截止**：2026-08-07 收盘  
> **报告属性**：主题供应链扫描 / 非投资建议  
> **数据口径**：A 股采用公司 2025 年报与东方财富口径交叉验证，行情由腾讯行情核对；海外公司以公司披露为主  
> **核心限制**：保密工程可能领先于公开证据；本报告判断的是“公开可验证成熟度”和“上市公司可投性”

---

## 一句话结论

**国产 EUV 是确定性很高的国家工程，但当前最紧的不是通用光学、光刻胶或真空泵，而是 EUV 级投影光学、稳定高功率光源与收集镜寿命、光化掩模检测和整机良率闭环。这四项仍缺少公开的国产工程化证据；A 股没有一家公司披露可归属 EUV 的收入、订单或客户验收。**

所以，这轮扫描的证券结论不是“买谁”，而是：**把 EUV 概念期权按零估值；只按现有 DUV、ArF、普通/先进掩模与通用量测业务给价。**

## 第一步：超级趋势确认

### 1.1 趋势是真的，但商业化还没被验证

| 标准 | 证据 | 判断 |
|---|---|---|
| 持续性 | 上海市科委披露 2008、2012、2018 年连续布局 EUV 任务；2025—2027 年仍设置 >100 W 中间焦点光源目标 | ✅ 3—5 年以上 |
| 物理性 | 需要光源、反射镜、掩模、工件台、真空、材料和整机联调 | ✅ 纯硬件/工程 |
| 规模性 | SEMI 2026 年中预测全球半导体设备销售额 **$1,659 亿**，其中 WFE **$1,439 亿** | ✅ 远超 $500 亿/年 |
| 加速性 | 2026 年设备销售预计 **+23.2%**；ASML 计划 2027 年低 NA EUV 产能在 2026 年约 65 台基础上 **+30%** | ✅ 全球需求加速 |

来源：[SEMI 2026 年中设备预测](https://www.semi.org/zh/node/173816)、[上海市 2025 年集成电路基础研究指南](https://www.shanghai.gov.cn/gwk/search/content/4023278979a246168587c99c615e4a27)、[ASML 2026Q2](https://www.asml.com/en/news/press-releases/2026/q2-2026-financial-results)。

### 1.2 已发生的验证事件

1. **2017-07-04**：长春光机所公开两镜 EUV 投影物镜和国内首幅 32 nm 线宽光刻胶图形；这是小视场原理曝光，不是 32 nm 芯片工艺。[长春光机所](https://ciomp.cas.cn/yw/201707/t20170704_7929594.html)
2. **2024-02-05**：上海硅酸盐所公开 20 kHz、约 100 μm 锡滴发生器稳定输出，是 LPP 光源的真实子系统进展。[上海硅酸盐所](https://www.sic.cas.cn/xwzx/kydt/202402/t20240205_6986198.html)
3. **2025-06-26**：上海将中间焦点 >100 W 电子束驱动等离子体 EUV 光源列为 2025—2027 年研究目标；目标本身说明该路线仍处研究期。[上海市政府](https://www.shanghai.gov.cn/gwk/search/content/4023278979a246168587c99c615e4a27)
4. **2025-12-17**：Reuters 援引匿名消息称深圳原型机已能产生 EUV 光，但尚未制造出可工作芯片。这是 B 级重要信号，不能替代客户验收。[Reuters 转载页](https://www.investing.com/news/stock-market-news/exclusivehow-china-built-its-manhattan-project-to-rival-the-west-in-ai-chips-4413119)
5. **2026-07-15**：ASML 将 2026 年收入指引上调至 €430—450 亿，并计划 2027 年低 NA EUV 产能 +30%，证明全球需求端还在加速。[ASML 2026Q2](https://www.asml.com/en/news/press-releases/2026/q2-2026-financial-results)

**供需缺口判断**：全球商业 EUV 需求增长高，ASML 正扩产；国产侧的问题不是“几台不够用”，而是公开可验证的 HVM 供给仍为零。**趋势确认：✅ 可长期追踪；当前不是可用订单验证的短缺交易。**

## 第二步：技术成熟度与物理拆解

### 2.1 先把“进展”分级

| 级别 | 必须出现的证据 | 国产公开状态 |
|---:|---|---|
| M0 | 论文、专利、设计 | 多环节已具备 |
| M1 | 单模块样机与可复现数据 | 光源、光学、锡滴、真空、工件台等已有进展 |
| M2 | 多模块原理集成并曝光 | **公开证据上限**：小视场/原理曝光 |
| M3 | 300 mm、全视场、扫描式工程机，同时披露 WPH、overlay、CDU、可用率 | 无公开硬证据 |
| M4 | 晶圆厂 SAT、重复批次、电学良率 | 无公开证据 |
| M5 | 付费交付、装机、收入、复购和服务收入 | 无公开证据 |

长春光机所与中科院光电所分别证明原理曝光和机械/真空系统存在；后者公开稳定 `5.8×10⁻⁷ Torr` 环境、纳米级调平调焦和自动上下片。两项都不等于高加速 300 mm 双工件台。[长春光机所](https://ciomp.cas.cn/yw/201707/t20170704_7929594.html)、[中科院光电所](https://ioe.cas.cn/xxgk/xgxx/KxYJ/201707/t20170721_4835459.html)

### 2.2 从整机拆到物理实体

```text
Layer 0：先进逻辑 / DRAM / HBM 晶圆制造
  ↓
Layer 1：EUV 扫描式光刻机、工艺套件、服务与升级
  ↓
Layer 2：子系统
  ├─ 13.5 nm LPP 光源：CO₂ 驱动激光 → 锡滴 → 等离子体 → 收集镜
  ├─ 照明/投影光学：超光滑镜坯 → Mo/Si 多层膜 → 波前校正
  ├─ 反射式掩模：低缺陷掩模坯 → 图形化 → pellicle → 修复
  ├─ 精密运动：掩模台 / 晶圆台 / 干涉仪 / 磁浮 / 减振
  └─ 真空与污染：氢气环境、锡碎屑、热漂移、真空阀与传感器
  ↓
Layer 3：制造与验证工具
  ├─ 原子级抛光/镀膜/波前量测
  ├─ 13.5 nm 光化掩模坯和图形掩模检测
  ├─ EUV 光刻胶、底层膜、显影、释气和随机缺陷控制
  └─ 设备控制软件、误差预算、配方库和良率数据库
  ↓
Layer 4：晶圆厂验证、长期运维、备件、训练与服务网络
```

ZEISS 公开资料显示，商业 EUV 光源由 TRUMPF 高功率 CO₂ 激光器每秒轰击约 5 万颗锡滴；投影系统由特殊多层膜反射镜构成。这说明“高纯锡”不是瓶颈，**稳定滴径、转换效率、收集镜寿命和整体同步**才是瓶颈。[ZEISS EUV 技术说明](https://www.zeiss.com/semiconductor-manufacturing-technology/inspiring-technology/euv-lithography.html)

### 3.1 瓶颈地图

**S 级（单点故障）**

1. **整机集成+良率闭环**：把分辨率、套刻、CDU、WPH、可用率、污染和维护同时做对，难度高于单个模块。
2. **EUV 投影光学**：原子级面形、多层膜界面和热稳定是真门槛；“会做光学镜片”不能映射。
3. **LPP 光源+收集镜寿命**：中间焦点功率、稳定性、转换效率、锡碎屑和镜面污染是一个系统问题。
4. **光化掩模检测+低缺陷掩模坯**：没有 13.5 nm 检测，就可能看不到真正在曝光时成像的缺陷。
5. **纳米运动与控制**：不只要精准，还要在高加速、高吞吐和长时间运行下精准。

**A 级**：EUV pellicle、污染/碎屑管理、组件寿命验证。  
**B+ 级**：EUV 光刻胶、底层膜、显影和随机缺陷控制。  
**非独立瓶颈**：通用真空泵、普通光学件、高纯锡、通用 CO₂ 气体、普通溅射靶材。它们可能参与供应链，但断货未必让 EUV 工程首先停摆。

### 3.2 国产工程最可能首先卡在哪里

1. **投影光学+光化量测**：最难通过通用工业能力“降级替代”，也最缺公开工程指标。
2. **光源稳定性与收集镜寿命**：产生 EUV 光已不是唯一问题；能否长时间稳定提供可用功率，才决定吞吐。
3. **整机误差预算+晶圆厂良率数据**：即使模块分别达标，仍需多年客户共研才能把设备变成产能。

全球标尺的同一检验：ASML 以 2026 收入 €440 亿为起点、+12% CAGR、30% 净利率，10 年年化约 **+5.5%**；HOYA 以 +10% CAGR、28% 净利率为 **+7.1%**；Lasertec 以 +12% CAGR、40% 净利率为 **+9.0%**。三家都是好生意，但按该方法当前价格都缺少 10% 年化的硬安全边际。

## 第六步：三家邻近代理的一页纸

### 路维光电（688401）——现有光掩模业务最纯，但不是 EUV 反射掩模

**为什么值得跟踪**：公司收入几乎全部来自掩模版，2025 年收入和净利均增长约 32%，经营现金流净额 ¥3.54 亿，现有业务是真实的。

**为什么不是 EUV 标的**：当前实现的是透射式光掩模与 40/28 nm 单片供货，而 EUV 需要反射式多层膜、极低缺陷掩模坯、pellicle 和 13.5 nm 光化检测。

**催化剂**：2026 年 28—14 nm 项目设备投建；40 nm 成套客户验证；IC 制造掩模收入占比提升。  
**风险**：显示掩模仍占主体；核心设备依赖进口；把 14 nm 布局误读为 EUV。  
**估值检验**：市值 ¥144.54 亿 / 收入 ¥11.55 亿 / PS 12.51x / PE 57.36x / +31.94%；10 年乐观回报 +11.95%。  
**结论**：**可作“先进光掩模国产化”单独研究，不可用“国产 EUV 核心股”买入。**

### 清溢光电（688138）——PS 最低，但工艺距离更远

**为什么值得跟踪**：PS 8.14x 在本组最低，现金流与收入为正；佛山新厂进入试生产，中高端 PSM/OPC 是可验证的近程升级。

**为什么不是 EUV 标的**：公司 2025 年实际能力为 180 nm 量产、150 nm 小批量，130—40 nm 尚在研发，28 nm 仍是规划。

**催化剂**：2026 年佛山工厂 PSM 量产；半导体掩模收入高于 2025 年的 ¥2.04 亿。  
**风险**：半导体掩模仅占总收入约 16.5%；2025 年定增 4,800 万股带来稀释；工艺节点与 EUV 有多代差。  
**估值检验**：市值 ¥100.89 亿 / 收入 ¥12.40 亿 / PS 8.14x / PE 53.95x / +11.46%；10 年乐观回报 +12.39%。  
**结论**：**加入“普通/先进光掩模”价格观察，不加入 EUV 正式观察名单。**

### 彤程新材（603650）——ArF 进展真实，EUV 收入仍为零

**为什么值得跟踪**：2025 年电子材料收入约 ¥9.86 亿、+32.39%；ArF 光刻胶收入在低基数上增长超 800%，多款 ArF/ArFi 产品已在多家客户稳定供货。这是比“布局 EUV”更硬的近程证据。

**为什么不是 EUV 标的**：年报的实际产品矩阵截至 ArF，并承认 EUV 高端市场由国际厂商主导；电子材料整体占收入约 28.7%，特定 EUV 纯度为零。

**催化剂**：ArF 重复订单、自研树脂占比和电子材料毛利率上升；若未来披露同步辐射线站 EUV 胶图形与晶圆厂联调，再升级评分。  
**风险**：主业仍有轮胎化学品；ArF 高增速基数小；EUV 材料需重新验证 RLS、释气与随机缺陷。  
**估值检验**：市值 ¥397.49 亿 / 收入 ¥34.29 亿 / PS 11.59x / PE 70.66x / +4.85%；10 年乐观回报 +4.62%。  
**结论**：**现价不具安全边际；只按 ArF 和电子材料业务评估。**

### 6.1 应直接排除的概念映射

- **福晶科技**：激光晶体/精密光学是现有业务，但 2025 年报未披露 EUV 或光刻机产品；动态市值约 ¥291.9 亿、PS 25.21x、PE 104.62x，不能给概念期权。
- **奥普光电**：历史调研记录已明确主营不涉及光刻机相关设备；动态市值约 ¥101.9 亿、PS 12.74x、PE 126.52x。
- **张江高科**：对上海微电子是少数股权间接映射，不是整机收入和现金流映射；少数股权折价与信息不透明应一起考虑。

## 第七步：反向验证

### 聪明人为什么不买

1. **国家工程的价值可能由非上市整机平台、晶圆厂和最终用户捕获**，概念公司不一定获得利润池。
2. **技术路线正确不等于工程时间短**。ASML 从早期原型到商业芯片经历近二十年；国产项目还要面对供应链分割。
3. **EUV 可被部分绕过，但不是免费的**：先进 DUV 多重图形化、Chiplet/先进封装、设计优化和纳米压印可降低部分 EUV 压力，却会增加步骤、成本或导入风险。
4. **EUV 成功对某些国产刻蚀/沉积代理未必全是利好**：它可以减少 DUV 多重图形化的部分重复步骤。
5. **估值已预支长期空间**：茂莱、芯源、中科飞测的 PS 红灯不能被“卡脖子”叙事覆盖。

### 最可能的分析错误

**将“公开信息不足”误判为“项目没有进展”。**保密工程可能已超过 M2；但对投资者而言，不能验证的进展也不能给确定估值。正确做法是保留技术上的开放性，同时在资本上要求证据。

### 论文破坏条件

| 观测信号 | 对结论的影响 |
|---|---|
| 官方/客户首次公开 300 mm 全视场扫描和 WPH、overlay、CDU、可用率 | 国产成熟度 M2 → M3，重做全部公司映射 |
| 出现晶圆厂 SAT、重复批次和电学良率 | M3 → M4，允许对真实参与公司给小部分期权价值 |
| 出现付费交付、合同负债、第二台/第二客户复购 | M4 → M5，才能按收入和利润估值 |
| 概念公司连续两期年报仍无 EUV 产品/客户证据 | 移出 EUV 观察，只按现有业务评估 |
| 终端先进制程需求下修 50% | 海外 EUV 设备/掩模/检测估值率先压缩；国产战略必要性不会消失，但商业回报更慢 |
