## 0. 信息丰富度评级与AI研究局限性

**信息丰富度评级：A级（信息充裕）**。

四方股份上市多年，已披露2025年年报、2026年一季报、权益分派公告与“提质增效重回报”行动方案；同时，电力设备、智能电网、新型电力系统、配网改造、新型储能等行业资料较丰富。因此本报告不把重点放在“资料堆砌”，而把重点放在：

1. 反面检验：好赛道是否真的转化为好利润？
2. 非共识风险：高毛利基本盘是否被低毛利新业务稀释？
3. 估值纪律：好公司是否已经被市场按“完美未来”定价？

**AI研究局限性声明**：资料多不等于确定性高。四方股份的真实确定性来自技术壁垒、客户认证、运行案例、毛利率、现金流和管理层资本配置，而不是来自报告长度。本报告对AIDC/SST、构网型储能、虚拟电厂、海外拓展等新业务均按“期权”处理，不把尚未充分验证的未来利润提前确认为核心价值。

## 4. 各维度分析摘要

### 4.1 商业模式：好生意，但不是“轻松生意”

1. **核心生意**：四方股份不是单纯卖硬件，而是卖电力系统安全、稳定、可控、可调度、可运维的工程化能力。
2. **护城河真实存在**：继电保护、电网自动化和稳控系统对可靠性要求极高，客户认证、运行案例、工程经验构成壁垒。
3. **定价权有限**：下游国网、南网、大发电集团、央国企客户强势，招投标机制决定技术优势更多体现为中标率和毛利稳定，而非随意提价。
4. **飞轮是“辛苦型复利”**：从继电保护/自动化基本盘外溢到新能源、储能、配网、智慧用电，但每个新场景都需要重新交付、验证和竞争。
5. **关键反面检验**：2025电厂及工业自动化毛利率23.92%，远低于电网自动化40.05%，说明增长业务可能稀释整体质量。

### 4.2 财务质量：好报表，贵价格

1. **成长连续性不错**：2021-2025营收从42.98亿元增至81.93亿元，归母净利从4.52亿元增至8.29亿元。
2. **现金流优秀**：2021-2025每年经营现金流均高于归母净利润，2025经营现金流12.25亿元，显著高于8.29亿元净利。
3. **ROE改善但毛利率下行**：ROE从2021年11.64%升至2025年17.75%，但毛利率从36.03%降至30.22%。
4. **资产负债表需跟踪**：2025应收账款14.49亿元、合同资产22.01亿元、存货23.25亿元，项目制营运资本占用不轻。
5. **估值缺乏安全边际**：约59x TTM PE、约60x P/FCF，要求公司未来多年持续高增长，容错空间不足。

### 4.3 行业格局：强β，但α并不轻松

1. **长期需求真实**：新能源装机、电气化、配网改造、新型储能、虚拟电厂共同提升电网复杂度，二次设备和自动化需求长期上升。
2. **2025行业数据支持**：全国电网投资6395亿元，其中110kV及以下配电网投资3218亿元，配网投资超过一半。
3. **四方产业链位置较好**：二次设备、保护控制、自动化、调度/站控相关环节比普通一次设备更接近“电力系统大脑和神经”。
4. **竞争强度高**：国电南瑞是体系型绝对龙头，许继电气有央企体系优势，东方电子在配网和用电数字化有竞争力。
5. **真正要跟踪的是利润归属**：行业有需求不等于供应商赚大钱，招投标和客户集中会把一部分利润转移给客户。

### 4.4 风险与治理：治理较规矩，经营风险来自扩张质量

1. **治理无明显红旗**：控股股东四方电气集团持股约39.07%，无质押；未见重大非经营占资或违规担保。
2. **分红股东友好**：2025年度每股派0.72元，合计约6.00亿元，分红率约72.37%。
3. **研发费用化为主**：2025研发投入7.32亿元，占收入8.93%；研发资本化比重约3.39%，利润没有明显靠研发资本化“做厚”。
4. **关键经营风险**：应收账款、合同资产、存货随收入扩张同步上升；若毛利率下行叠加现金流恶化，应迅速降低质量评分。
5. **传承与组织风险**：公司是技术型民企，核心技术文化和管理层代际传承需要持续观察。

## 5. 投资论点：Bull vs Bear

### 🟢 看多逻辑

1. **新型电力系统是长期真需求**：新能源高渗透、配网改造、储能调度、虚拟电厂共同提高电力系统复杂度。
2. **公司处在高价值二次设备环节**：继电保护、稳控、自动化、安全控制比普通硬件更难被低价替代。
3. **财务质量较好**：收入、利润、扣非利润、经营现金流连续增长，现金流长期覆盖利润。
4. **高分红和低研发资本化加分**：管理层目前表现出较强资本纪律，不像单纯讲故事的成长股。
5. **业务矩阵有协同**：电网自动化基本盘可向新能源场站、配网、储能、智慧用电、数据中心电力系统外溢。
6. **行业政策和投资方向匹配**：配网高质量发展、新能源消纳、调节能力优化、南网固定资产投资等都与公司产品相关。
7. **新业务有期权价值**：构网型储能、绿电直连、AIDC 800V SST、海外市场若兑现，利润天花板可能上移。

### 🔴 看空逻辑

1. **估值显著偏贵**：当前约59x TTM PE、约60x P/FCF、约10x PB，已经按高成长定价。
2. **定价权不强**：客户集中且专业，国网/南网/大发电集团通过招投标压制供应商利润率。
3. **毛利率下行**：2025综合毛利率30.22%，较2021年36.03%明显下降；各业务毛利率2025均同比下滑。
4. **新业务可能低毛利化**：储能、综合能源、工商业用电、AIDC若偏工程总包/系统集成，可能做大收入但稀释利润。
5. **强竞争者压制**：国电南瑞、许继电气、东方电子等在体系资源、规模、平台能力上均有压力。
6. **营运资本压力不小**：2025应收+合同资产+存货规模较高，若验收/回款变慢，现金流会先恶化。
7. **当前价格缺少容错**：即使乐观情景下合理股价约44-58元，也仅接近当前60.96元；基准情景则明显缺乏安全边际。

### 7.4 关键催化剂

**加仓/上调信号：**

1. 电网自动化毛利率稳定在40%左右，未被招标压价显著侵蚀。
2. 新业务订单放量同时毛利率不低于公司平均，证明不是低毛利集成。
3. 经营现金流/净利润持续>1，应收+合同资产/收入不继续上升。
4. 海外或AIDC/SST出现可验证的大客户订单和稳定毛利，而非概念披露。
5. 股价回到能提供30%-50%安全边际的区间。

**减仓/下调信号：**

1. 综合毛利率继续明显下滑，尤其电网自动化毛利率跌破35%。
2. 收入增长但经营现金流连续两年低于净利润70%。
3. 应收账款+合同资产/收入连续超过50%且继续恶化。
4. 新业务收入占比提升但净利率、ROE、FCF同步下降。
5. 大额并购、激进扩产、研发资本化比例显著抬升或关联交易异常扩大。
