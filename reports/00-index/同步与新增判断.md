# 同步与新增判断

结论：这个库连接的是你自己的 OneDrive/Remotely Save，不是 Git 仓库自动拉取别人的更新。

## 为什么会出现“我没更新过但内容变了”？

Windows 文件有两个容易混淆的时间：

- **创建时间**：文件什么时候出现在本地文件系统。
- **修改时间**：文件内容或同步程序最后一次写入的时间。

OneDrive/Remotely Save 同步旧文件时，可能会刷新“修改时间”，于是它会出现在“最近修改”里，看起来像刚新增。

## 这次核验样本

- `领益智造/领益智造投资研究报告-20260707.md`：创建时间 2026-07-07 17:40:57，修改时间 2026-07-08 13:00:12。说明它不是刚才新建的，而是旧文件后来被重写/同步。
- `bottleneck-map/master-map.md`：创建时间 2026-07-06 13:02:02，修改时间 2026-07-08 12:58:00。也是旧文件被改了修改时间。
