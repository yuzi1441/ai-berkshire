# 新增内容规则

你之后还会持续新增内容，所以这个库采用“**旧内容稳定 + 索引可刷新 + 新内容有入口**”的方式管理。

## 新内容放哪里？

### 1. 明确公司/主题

直接放进对应目录：

- 公司研究：`公司名/报告名.md`
- 行业研究：`行业或主题名/报告名.md`
- 资料来源：优先放到对应公司/主题目录下，或后续统一进 `_sources/`。

### 2. 暂时不知道怎么归类

先放：

- `_inbox/YYYY-MM/报告名.md`

等每周/每批整理时再归档。不要为了“立刻分类正确”卡住写作。

## 新报告建议 frontmatter

复制 [[_templates/投资报告模板|投资报告模板]]，至少保留这些字段：

```yaml
title: ""
date: 2026-07-08
workflow: research
company: ""
ticker: ""
market: ""
status: draft
decision: watch
tags: [investment]
```

## 新增后怎么办？

有两种方式：

1. 你对 Codex 说：**刷新 reports 索引**。
2. 或者在终端运行：

```powershell
cd "C:/Users/whatn/Desktop/vibecoding/codex/投资分析/ai-berkshire/reports"
node .\_scripts\refresh_obsidian_indexes.mjs
```

刷新后这些页面会自动更新：

- [[00-index/投资研究总览|投资研究总览]]
- [[00-index/最近更新|最近更新]]
- [[00-index/目录导航|目录导航]]
- [[00-index/工作流索引|工作流索引]]
- 各大目录的 `MOC.md`

## 我建议的长期规则

- 不追求一次性把旧库整理完。
- 新内容尽量从今天开始规范。
- 旧内容靠索引和 MOC 提升可读性。
- 真要移动旧文件时，每次只移动一小批，并保留索引页中的旧路径记录。
